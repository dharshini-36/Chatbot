# 🧠AGI Chatbot

A simple and interactive AI chatbot built using **Streamlit** and **Groq API**.
This project demonstrates a conversational AI interface with chat memory and fast responses.

---

## 🚀 Features

* 💬 Interactive chat interface
* ⚡ Fast AI responses using Groq
* 🧠 Maintains conversation history
* 🔐 Secure API key handling using `.env`
* 🌐 Deployable on Streamlit Cloud

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Groq API
* python-dotenv

---

## 📁 Project Structure

```
Dharshini-AGI
│
├── DharshiniAGI.py   # Main chatbot app
├── requirements.txt  # Dependencies
├── .gitignore        # Ignore sensitive files
└── .env              # API key (not uploaded to GitHub)
```

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/Dharshini-AGI.git
cd Dharshini-AGI
```

---

### 2️⃣ Install dependencies

```
pip install -r requirements.txt
```

---

### 3️⃣ Add API Key

Create a `.env` file and add:

```
GROQ_API_KEY=your_api_key_here
```

---

### 4️⃣ Run the app

```
streamlit run DharshiniAGI.py
```

---

## 🌍 Deployment (Streamlit Cloud)

1. Push code to GitHub
2. Go to Streamlit Cloud
3. Click **New App**
4. Select repository
5. Add Secrets:

```
GROQ_API_KEY="your_api_key"
```

---

## 📌 Notes

* Do NOT upload `.env` file to GitHub
* Always keep your API key secure
* Use `.gitignore` to hide sensitive files
